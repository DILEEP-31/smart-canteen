  1. Verify MySQL Service is Running:

    In Windows PowerShell (as Administrator), run: Get-Service -Name *mysql* or start it with Start-Service MySQL267 (or your MySQL service name).

  2. Check .env Database Credentials:

    Make sure .env in this project folder contains your correct credentials:

    DB_HOST=localhost

DB_USER=canteen_app
DB_PASSWORD=your_actual_mysql_password
DB_NAME=college_smart_canteen

    If user canteen_app has not been created yet in MySQL, run this in SQLyog (or MySQL command line):

    CREATE USER IF NOT EXISTS 'canteen_app'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON college_smart_canteen.* TO 'canteen_app'@'localhost';
FLUSH PRIVILEGES;
  4. Verify Database Exists:

    Ensure schema.sql was executed in SQLyog and the college_smart_canteen database is populated.
